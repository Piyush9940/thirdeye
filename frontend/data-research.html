Dataset Categorization & Integrity Rules
To preserve scientific transparency, all datasets below are strictly categorized into: [Measured Satellite Observations], [Climate Context], [Experimental Model Estimates], and [Evaluation Metrics]. Never treat experimental model estimates as measured ground truth.
Category 1

Measured Satellite Observations

226 Records • QA ≥ 0.50

Aggregated total column atmospheric methane measurements ($X\text{CH}_4$ in ppb) from Copernicus Sentinel-5P TROPOMI. Spans 4 temporal snapshot months (May 2019, Feb 2021, Aug 2021, Nov 2023). Contains median precision, pixel counts, and distance-to-node metrics.

Category 2

Spatial Lattice & Geospatial Boundaries

255 Nodes • 2° Grid

The 255 spherical grid nodes discretizing the Indian subcontinent [7°N–37°N, 69°E–97°E]. Includes graph topology metrics (node degrees, connected components) and observation presence flags, alongside the official India ADM0 polygon.

Category 3

Climate Context (NASA POWER Meteorology)

Collocated Features

Surface meteorological parameters collocated with each observation node from the NASA POWER reanalysis project. Variables include 2m Air Temperature (T2M), Precipitation (PRECTOTCORR), Relative Humidity (RH2M), and 10m Wind Speed (WS10M). Embedded within methane_observations.csv.

Category 4

Experimental ML Model Estimates

720 Predictions • Not Measured Truth

Out-of-sample predictions generated by the experimental Multi-Layer Perceptron (MLP) reference model evaluated across 3 chronological folds and 5 random seeds (7, 21, 42, 77, 123). Provided strictly for model evaluation, residual analysis, and reproducibility.

Download Predictions CSV (720 rows) Download Predictions JSON
Category 5

Chronological Evaluation Metrics & Metadata

15 Seeds • 3 Folds

Rigorous evaluation metrics (MAE, RMSE, R², Bias) across folds and random seeds, accompanied by complete pipeline metadata and scientific release documentation.
