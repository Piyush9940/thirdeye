Experimental Reference Model Not Production Approved 15 Verified PyTorch Checkpoints

Machine Learning Experiment Explorer & Live Predictor

Scientific transparency dossier detailing model architectures, chronological validation across 3 folds and 5 random seeds, benchmark comparisons against Graph Neural Networks (GCN), and an interactive experimental test bench.

Mandatory Scientific Integrity Standard The machine learning models developed in this project are experimental research reference baselines, NOT operational environmental forecasting engines. Negative $R^2$ across chronological evaluation folds indicates performance does not beat the historical target mean. Negative bias indicates systematic underprediction. Graph Neural Networks did not outperform the multi-layer perceptron. Predictions must never be cited as true future forecasts or proof of ground emissions.
Model Architecture: Original MLP Reference PyTorch 2.x

NETWORK SPECIFICATIONS

  • Input Dimension: 8 continuous standardized features
  • Hidden Layer: 32 linear units + ReLU activation
  • Regularization: Dropout ($p = 0.20$)
  • Output Layer: 1 linear unit (Standardized $X\text{CH}_4$, rescaled to ppb)
  • Training Strategy: Adam optimizer, 250 epochs, MSE loss
  • Checkpoint Count: 15 models (Folds 1, 2, 3 × Seeds 7, 21, 42, 77, 123)

THE 8 INPUT FEATURES (IN EXACT ORDER)

1. T2M (Air Temp)
2. PRECTOTCORR
3. RH2M (Humidity)
4. WS10M (Wind Speed)
5. Latitude (°N)
6. Longitude (°E)
7. Month Sine
8. Month Cosine
